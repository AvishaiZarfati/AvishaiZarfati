### [AI-Powered Solar Flare Forecasting](https://avishai-portfolio.netlify.app/surya_flare_forecasting)

**AI-Powered Solar Flare Forecasting** is a **fine-tuned NASA’s Surya foundation model** to forecast the probability of M/X-class solar flares in the next 24 hours. The project includes a reproducible GPU pipeline for data preparation, training, inference, and evaluation built with **Python 3.11, CUDA PyTorch, A100 GPU, persistent NFS**. This project showcases my skills in **Fine-tuning SOTA Models**. You can check out the repository [here]([project_2_repository_link](https://github.com/AvishaiZarfati/Surya-Foundation-Model-for-Heliophysics)).
